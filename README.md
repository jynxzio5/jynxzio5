### About Me

Welcome to my profile. I am a software engineer and vibecoder focused on low-level system architecture, desktop application engineering, and high-performance product design. My technical scope includes native toolchains, process injection loaders, modern web infrastructure, and stateful Discord bot systems.

- **Software Architecture & Security**: Auditing, reversing, and hardening application runtimes. Crafting modular architectures built for execution speed and structural integrity.
- **Desktop & Utilities Ecosystem**: Designing and maintaining **Opela Nexus** (a localized desktop store application with complex modularity), **Clicky** (specialized gaming automation and macro execution engine), and native loaders.
- **Reverse Engineering & Memory Tooling**: Developing open-source game loaders such as **Mono-Injector** and custom in-game UI menus with real-time memory offset hooks.
- **Discord Bot Systems**: Engineering Discord bot architectures with role-based access control (RBAC), state machines, and synchronized game logic.
- **Full-Stack Engineering**: Implementing localized JSON data normalization, API protocol bindings, and responsive user interfaces with TypeScript, React, and Next.js.
